# 🎯 Guess My Number

A simple interactive number-guessing game built with **HTML, CSS, and JavaScript**.

## 🎮 How It Works

Guess the hidden number between **1 and 20**. Each wrong guess reduces your score by 1. Guess correctly to reveal the number and try to achieve a high score.

## ✨ Features

- Random number generation
- Score & high-score tracking
- Dynamic game messages
- Restart functionality
- Responsive design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
